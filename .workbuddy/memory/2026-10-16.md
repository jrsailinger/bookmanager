## 纸质藏书管理 Web 应用（从零搭建完成）

**项目路径**：`E:/wb_tool/bookmanager_wb`（项目根即仓库根）

**技术栈**：React 18 + TypeScript + Vite 5 + Tailwind CSS 3 + Dexie 4（IndexedDB）+ Zustand 5 + Lucide

**核心约束（用户明确要求，后续改动不得违反）**
- 纯前端、零后端、运行时零网络请求，所有资源本地加载
- 业务数据只存 IndexedDB（库名 `PaperBookManagerDB`，表 `books`），禁止 localStorage 存业务数据；
  localStorage 仅存主题偏好 `pbm:theme`
- 不做扫码 ISBN、不接任何图书 API、不含借阅管理
- 图书字段中仅「书名」必填，其余全选填；封面以 Blob 存库，无封面用「书名首字 + 稳定 HSL 色块」占位
- 导入必须增量，绝不覆盖：有 ISBN 按规范化 ISBN 判重，无 ISBN 按「书名+作者」判重，同书名不同 ISBN 视为两本

**目录约定**
- `src/types` 类型 / `src/services` 数据层（唯一接触 Dexie 的地方）/ `src/store` Zustand /
  `src/hooks` 派生与初始化 / `src/utils` 纯函数 / `src/components/{ui,layout,book,import,stats,settings}`
- 全局样式类：`.wb-input` / `.wb-label` / `.wb-card` 定义在 `src/index.css`

**已验证**
- `tsc --noEmit` 无错；`npm run build` 通过（dist 约 312KB JS / 33KB CSS，gzip 100KB / 6KB）
- 自测 19 项全通过：CSV 解析（引号转义/字段内换行/BOM/分号分隔/空行过滤）、base64↔Blob 往返、
  首字提取、色块稳定性、日期与备份文件名格式（测试脚本跑完已删除）
- `vite preview` 返回 200；产物内无运行时外部请求（残留 url 仅为 XML namespace 与 React 报错文档字符串）

**未做浏览器端真机交互验证**：未使用无头浏览器点击验证 UI，仅通过类型检查 + 构建 + 预览 HTTP 200 确保可运行。
